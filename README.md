# 数据库系统原理实验

本科《数据库系统原理》课程实验,数据库为 MySQL 8.x,含四个实验和一个综合课程设计。

## 目录结构

| 目录 | 内容 |
| ---- | ---- |
| `实验1/` | 数据库与表的定义(SQL 脚本 + 建表/模式图截图) |
| `实验2/` | 单表与多表查询、嵌套查询等(SQL 脚本 + 运行结果截图) |
| `实验3/` | 视图、用户与权限管理、存储过程、触发器(`6/10/12/13` 为对应题号截图) |
| `实验4/` | 数据库编程:Python + PyMySQL 连接数据库、建库脚本、学生选课 E-R 图及截图 |
| `实验4/教务管理系统/` | 综合设计:基于 Flask 风格分层的教务管理系统(PyMySQL) |

## 教务管理系统

```
cd 实验4/教务管理系统
pip install -r requirements.txt
# 修改 config.py 中的数据库账号密码
python app.py
```

> 数据库账号密码在 `实验4/db.py` 与 `实验4/教务管理系统/config.py` 中,为本机 MySQL 的本地配置,使用前请改成自己的。

## 说明

- 每个实验目录下的 `数据库实验N.sql` 为完整可执行脚本,`*.png` 为对应运行结果截图。
- `数据库系统原理.docx` 为实验报告,`数据库系统概论实验指导书-2026.pdf` 为课程实验指导书。
